# Hearth · 炉火

> **状态：开发中。** 功能在陆续补，界面和结构都可能变。

一个用 C# / .NET 9 + WPF 写的 Minecraft: Java 版启动器，个人自用。

## 目录结构

```
启动器/
  build.ps1        一键构建：编译 Release 并把成品放到 dist/
  dist/            成品目录（Hearth.exe 在这里，双击即用，可整个拷走）
  src/             源码
  assets/          界面资源（背景图等）
  docs/            资料
    icon/          图标源文件（svg / png / ico 设计稿）
    design/        早期界面设计稿
    shots/         截图
  _test/           测试工程（装箱/启动/安装等命令行验证用）
```

## 怎么运行

双击 `dist\Hearth.exe`。

改过代码之后：运行 `build.ps1`，它会重新编译并把新的 exe 放进 `dist`。

## 能做什么

- 版本选择：按正式版 / 预览版 / 远古版 / 愚人节版分类，置顶最新版本
- 版本下载：原版、Fabric、Forge、NeoForge，自动解决依赖
- 整合包导入：CurseForge、Modrinth、以及带 `versions/` 的 `.minecraft` 目录
- 资源中心：Modrinth 搜索，mod / 资源包 / 光影 / 数据包
- 版本设置：概览、启动参数、版本隔离、加载器增减、Fabric API、Mod 管理、导出
- 多游戏文件夹、版本隔离、Java 缺失时确认后自动下载
- 微软正版登录（多账号切换）、真实皮肤头像、皮肤与披风更换
- 主题皮肤（可解锁）、标题栏自定义、界面动画开关
- 统一下载进度球：安装版本、装加载器、导整合包、下 mod 都走同一个进度
