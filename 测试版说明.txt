Hearth（炉火）0.4.4-beta  测试版说明
=====================================

这是什么
--------
一个 Minecraft Java 版启动器，我自己写的，现在还是个半成品，想找人先帮忙试试看。

怎么装
------
1. 双击 Hearth-0.4.4-beta-Setup.exe
2. 一路下一步（默认装到你的用户目录，不需要管理员权限）
3. 装完桌面上会有 Hearth 的图标，双击打开
4. 想卸掉：设置 → 应用 → 找到 Hearth → 卸载

第一次打开游戏列表是空的，按下面来：
1. 点左边「下载」→「版本下载」，挑一个版本装（推荐先从 1.20.1 原版试）
2. 装好回「版本选择」，点那个版本，右边点「开始游戏」
3. 想登录正版：点左上角账户区，走微软验证码登录（会开浏览器）
4. 没有正版也能玩：账户 → 离线登录，随便填个名字

目前能做什么
------------
- 装原版 / Fabric / Forge / NeoForge
- 导入整合包（CurseForge、Modrinth 的 zip，或者带 versions 文件夹的 .minecraft 目录）
- 资源中心搜 Modrinth 的 mod / 资源包 / 光影
- 微软正版登录，能进正版服务器，支持多账号切换
- 离线登录、第三方皮肤站账号
- 皮肤、披风更换
- 版本设置：内存、Java、版本隔离、增减加载器、Fabric API、OptiFine、导出整合包
- 游戏崩了会自动分析原因，告诉你大概率是哪个 mod / 哪一步出的问题
- 下载支持断点续传和文件校验，网络不稳也不容易装坏
- 启动器自己能检查更新（有新版会在右下角提示）

这一版修了什么
--------------
- 整合包（尤其 1.12 及以下的老包）加载器识别：现在会顺着父版本找，不再一律显示「原版」
- 4K / 高缩放下窗口会顶出屏幕：现在会按屏幕工作区自动收回来
- Java 版本推断：老版本没写 javaVersion 时不再一律当成 17

已知问题（别当 bug 报）
------------------------
- 4K 或者缩放不是 100% 的屏幕上，个别弹窗的排版可能还需要再调
- 目前只有中文

遇到问题怎么反馈
----------------
1. 截图（界面、报错都行）
2. 游戏崩了：把 %TEMP%hearth-launch.log 或者游戏自己的崩溃报告发出来
3. 装版本出错：%TEMP%hearth-install.log
4. 直接群里说，或者私聊我也行

注意
----
- 这个版本还在改，界面和功能都可能变，别拿它当正经启动器用
- 你自己的存档、mod 建议先备份一份
- 出问题别慌，日志留着发给我是最有用的

谢谢帮忙测试
